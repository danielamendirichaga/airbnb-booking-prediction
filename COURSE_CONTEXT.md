# Course Context

This repository contains a public-facing version of a final project completed for:

- Course: `ECON 425T: Machine Learning for Economists`
- Institution: `UCLA`
- Progam: Master of Science in Quantitative Economics (MQE)
- Term: `Winter Quarter 2026` 

## Project Framing

The original class project studied whether machine learning could predict whether a Los Angeles Airbnb listing-night was booked rather than open using repeated Inside Airbnb snapshots and related external data.

The modeling workflow focused on predictive performance rather than causal inference.

## Assignment-Style Deliverables Included

- A final written report: `Report_FinalProject_DMM.pdf`
- An end-to-end notebook: `project/airbnb_booking_prediction.ipynb`
- Exported figures and tables used in the final analysis

## Public Repository Note

This GitHub repository is a cleaned, portfolio-friendly version of the original class submission. Large raw data files, generated processed datasets, cache files, and duplicate export bundles are excluded from version control to keep the repository easier to navigate and share.

The original submission-oriented materials are preserved in:

- `project/README_submission.md`

## Reproducibility Note

Because the original project used large raw and processed files, this public version is intended to showcase the methodology, modeling workflow, report, and outputs rather than function as a fully self-contained data bundle.
